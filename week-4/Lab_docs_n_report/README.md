Week 4: LLM Fine-tuning (SFT & DPO)

This folder contains the scripts and reports for Lab 4, focusing on fine-tuning Qwen2.5-0.5B using Supervised Fine-tuning (SFT) and Direct Preference Optimization (DPO).

🚀 Models on Hugging Face

    Original SFT mistral-7B gpt4 Model:[https://huggingface.co/lizzieO7/mistral-7b-finetune]

    SFT Qwen gpt4 Model:[https://huggingface.co/lizzieO7/Qwen-finetune-test]

    SFT Qwen Pirate Model: [https://huggingface.co/lizzieO7/Qwen2.5-0.5B-Pirate-Final]

    DPO Qwen Aligned Model: [https://huggingface.co/lizzieO7/Qwen2.5-0.5B-DPO-Aligned]

📁 Files in this Directory

    finetune_sft.py: Script for SFT training with Pirate dataset.
    
    finetune_dpo.py: Bonus Challenge - DPO training for logical alignment.

    compare_sft.py: Evaluation script for SFT performance.
    
    compare_dpo.py: Evaluation script for DPO performance.
    
    training_loss.png: Visualized loss curve for the pirate SFT phase.

    Reflection_Report_Lab4.pdf: Detailed reflection report of the experiment process.
